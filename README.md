# YubiSVG — iPhone対応のSVGエディター

スマホの指で描ける、ベジェ曲線対応のお絵描きツール。PC・MCPサーバーなしで動作します。

## 🌐 サイトを開く

**[YubiSVGを開く](https://shugurerune.github.io/yubisvg-web/)**

> 初回はリポジトリの **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** が必要です。
> GitHub Pagesが有効になるまでは上のURLは表示されません。

## できること

- **立ち絵・写真を下絵として読み込み、SVGをトレース（v0.5）**
- 下絵の透明度・サイズ・位置調整・表示切替
- 指描き・ベジェ曲線の編集・先端が尖った毛束の作成
- 拡大・移動・レイヤーの選択／ロック
- SVG画像の保存
- 再編集用JSONの保存と読み込み
- Undo / Redo
- ChatGPTとのコピー＆ペーストによるパーツ単位の共同編集

### 画像を下絵として使う（v0.5）

1. iPhoneのSafariで **「🖼 下絵読み込み」** を押し、画像を選択（PNG/JPEG/WebP・対応環境ではHEIC）。
2. **透明度**を調整して「指描き」「ベジェ」で輪郭をなぞる。
3. **「🖼 下絵移動」** を選ぶと、指で下絵の位置を動かせる。**サイズ**で拡大縮小、**中央へ**で中央配置。
4. **「下絵を隠す」** で描いた線だけを確認できる。
5. **「SVG保存」** は下絵を除いたSVGだけを書き出す。**「編集データ保存」** は下絵を含めたJSONを保存するので、再編集できる。

下絵画像は端末内のブラウザに保存します。GitHubやChatGPTへの自動アップロードはありません。
ブラウザのデータ削除で下絵が失われることがあるため、再編集用JSONをこまめにバックアップしてください。
サイズの大きな画像は縮小・圧縮して保存します。SafariでHEICの読込みができない場合は画像をJPEG/PNGに変換してください。

### ChatGPTで修正する

1. キャンバスで編集するパーツを選択する。
2. **「✦ AIに送る」→「文章をコピー」**。
3. コピーした文章をChatGPTに貼り付け、どう変えたいか伝える。
4. ChatGPTが返したJSONをコピーする。
5. YubiSVGの **「⇥ AI修正を貼る」** に入力し、確認して適用する。

ChatGPTとは自動接続ではありません。コピー＆ペースト方式です。

## プライバシー

この公開サイトに作品の自動アップロード機能はありません。編集データはこの端末のブラウザ内に保存されます。
Safariのデータ消去や端末変更で消えることがあるので、**「編集データ保存」**でJSONをこまめにバックアップしてください。

公開しているのはエディター本体（`index.html` と `client/` 内のスクリプト）のみです。
[MCP・PC同期機能の開発用リポジトリ](https://github.com/ShugureRune/svg-editor)にあるサーバーコードや作品ファイルはこのリポジトリに含めていません。

## 注意

- AI修正ができるのは、現在ベジェ曲線の制御点またはパーツの色・線幅です。
- 普通のSVGファイルを読み込んで再編集する機能はまだありません。編集用JSONを使ってください。
- スマホSafariでの実機操作感は今後確認して調整する段階です。
