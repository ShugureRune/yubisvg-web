# YubiSVG — iPhone対応のSVGエディター

スマホの指で描ける、ベジェ曲線対応のお絵描きツール。PC・MCPサーバーなしで動作します。

## 🌐 サイトを開く

**[YubiSVGを開く](https://shugurerune.github.io/yubisvg-web/)**

> 初回はリポジトリの **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** が必要です。
> GitHub Pagesが有効になるまでは上のURLは表示されません。

## v0.6.1：iPhoneの下絵描画を高速化

下絵画像を表示しているときに、指描き・画面移動・ズームで極端に重くなる問題を修正しました。
下絵画像のSVG要素を毎フレーム再生成せず、一度読み込んだ画像を使い回すようになっています。
また、非表示のレイヤーパネルのDOMを毎フレーム作り直さないようにしました。

既存の編集内容・下絵画像データ・保存ファイルの形式は変わりません。Safariでは画面左上が **v0.6.1** と表示されたことを確認してください。

## v0.9.0：AI半自動補完（続きを描く・隙間を閉じる・左右反転）

**「✦ AI半自動補完」**で、選択中のベジェ図形に対して3種類の操作ができます。

1. **続きを生成（ChatGPT）**：開いたベジェパーツを選択し、「✦ AI半自動補完」→「ベジェの続きを生成」。依頼文をコピーしてChatGPTに渡し、返されたJSONを「補完JSONを貼る」へ貼り付けるとプレビューできます。既存の制御点は保持し、最後の出力ハンドルと新しいアンカーだけを変更します。
2. **隙間を補完（ChatGPT）**：開いたパーツ（3アンカー以上）を選択し、「開いた輪郭の隙間を補完」。始点と終点をつなぐ2つの制御ハンドルをChatGPTに提案させます。プレビューでは閉じた図形となり、塗り色が未設定なら線の色で塗ります。
3. **左右反転パーツ（オフライン）**：ベジェパーツを選択し、「左右反転パーツを追加」。対称軸X（0〜800）を指定すると、元の図形を変えずに左右反転した**新規パーツ**をプレビューします。ChatGPTとの通信は不要です。

プレビュー後は **「✓ 補完を確定」** または **「✕ 破棄」** を選択します。プレビューは編集データやSVG保存に含まれません。確定後はUndoで取り消せます。

安全仕様：

- ChatGPTからのJSONは `documentId`、`expectedRevision`、`elementId`、`baseElementHash` が一致するときのみ受理。
- `extendBezier` は `endOut` と追加する `anchors`（1〜60個）だけ、`closeGap` は `endOut` と `startIn` だけを指定可能。既存の別パーツへの変更や任意の命令は拒否。
- 同じパーツIDを維持して編集するのは続きを生成・隙間補完の場合だけ。左右反転では新しいIDを採番し、元のパーツはそのまま。
- v0.7・v0.8 の既存機能、下絵表示の高速化、編集用JSON形式は変わりません。
- **下絵画像から色の境界を自動検出する機能は未実装**です（画像解析・輪郭抽出は別の開発段階で扱います）。

開発者向けテスト：`node --test tests/rough-to-bezier.test.cjs tests/ai-create.test.cjs tests/ai-complete.test.cjs`

## v0.8.0：ChatGPTで新しいSVGパーツを生成

既存パーツの編集に加えて、**新規ベジェ図形の追加**に対応しました。ChatGPTとの通信は引き続き手動コピー＆ペーストで、作品や下絵の自動アップロードはありません。

1. 画面上部の **「✦ AI新規作成」** を押し、「依頼文をコピー」で作品ID・版番号・既存パーツの概要をコピーする。
2. ChatGPTに貼り付け、**「追加したい新規パーツ：」** の後に髪の束・目・服などの希望を伝える。下絵を使う場合は「下絵をChatGPTに渡す」で画像を別途添付する。
3. ChatGPTが返す `createElement` または `createElements` のJSONをコピーする。
4. YubiSVGで「✦ AI新規作成」→ **「⇥ 生成JSONを貼る」** → **「👁 プレビューを確認」**。
5. 水色の輪郭を確認し、**「✓ このパーツを追加」** で新規パーツを末尾に追加。**「✕ 破棄」** なら元の作品を維持。

安全設計：

- JSONの `documentId` と `expectedRevision` を照合。版番号が変わっているときは再度依頼文をコピーする。
- 新規パーツは `kind: "bezier"` のみ、最大12個/回、制御点は1パーツ最大160個・合計600個、座標は-2000〜2000。
- AIが `id`、`locked`、削除命令などを指定すると拒否。確定時にエディター側でパーツIDを割り当て、既存パーツには触れません。
- プレビューはSVG保存や編集データ保存の対象外です。**確定後はUndoで追加したパーツをまとめて取り消せます。**
- 開発者向けテスト：`node --test tests/ai-create.test.cjs`

## v0.7.0：ラフを編集できるベジェ図形に変換

iPhoneの「✎ 指描き」でなぞったラフ線を、「✦ ラフを図形化」で**新しいベジェ制御点に変換**できます。

1. 「✎ 指描き」でラフ線を描く。線を描いた直後はその線が選択されています。
2. 「✦ ラフを図形化」を押す。別のラフ線を使いたいときは「↖ 選択」で選んでから押す。
3. 水色のプレビューを見ながら「細かさ」を調整する。輪郭を塗る図形なら「閉じて塗る」をオンにする。
4. 「✓ 確定」で元のラフ線をベジェに置き換える。白いアンカーと青いハンドルで微調整できる。「✕ 破棄」なら元のラフ線を一切変更しない。

- プレビューは編集データ、SVG保存、Undo履歴には含まれません。
- 確定時に**選んだラフ線だけ**が同じパーツIDのベジェ図形になり、他のパーツや下絵は変わりません。確定後は「↶ 戻す」で復元できます。
- RDPによる点の間引き＋弱い平滑化＋角を保護したベジェ変換で、制御点の増えすぎを抑えます。図形化は端末内で実行され、AIへの自動送信はありません。
- スマホの描画領域をプレビュー中に誤操作しないよう、確認パネルを開いている間はキャンバスの編集を停止します。
- 開発者向けテスト：`node --test tests/rough-to-bezier.test.cjs`

## できること

- **立ち絵・写真を下絵として読み込み、SVGをトレース（v0.5）**
- **下絵画像をChatGPTへ手動共有・保存・コピー（v0.6）**
- 下絵の透明度・サイズ・位置調整・表示切替
- 指描き・ベジェ曲線の編集・先端が尖った毛束の作成
- 拡大・移動・レイヤーの選択／ロック
- SVG画像の保存
- 再編集用JSONの保存と読み込み
- Undo / Redo
- ChatGPTとのコピー＆ペーストによるパーツ単位の共同編集

### 画像を下絵として使う（v0.5）

1. iPhoneのSafariで **「🖼 下絵読み込み」** を押し、画像を選択（PNG/JPEG/WebP・対応環境ではHEIC）。
2. **透明度**を調整して「指描き」「ベジェ」で輪郭をなぞる。
3. **「🖼 下絵移動」** を選ぶと、指で下絵の位置を動かせる。**サイズ**で拡大縮小、**中央へ**で中央配置。
4. **「下絵を隠す」** で描いた線だけを確認できる。
5. **「SVG保存」** は下絵を除いたSVGだけを書き出す。**「編集データ保存」** は下絵を含めたJSONを保存するので、再編集できる。

下絵画像は端末内のブラウザに保存します。GitHubやChatGPTへの自動アップロードはありません。
ブラウザのデータ削除で下絵が失われることがあるため、再編集用JSONをこまめにバックアップしてください。
サイズの大きな画像は縮小・圧縮して保存します。SafariでHEICの読込みができない場合は画像をJPEG/PNGに変換してください。

### 下絵画像をChatGPTに渡す（v0.6）

1. Safariで「下絵読み込み」から画像を選ぶ。
2. **「✦ 下絵をChatGPTに渡す」** を押すと、下絵のプレビューと共有方法が表示される。
3. **「共有メニュー」** からChatGPTを選べる場合は選択。表示されなければ **「画像を保存」** を押して、このチャットの「＋」からPNGを添付する。
4. 対応しているSafariでは **「画像をコピー」** も使える。ChatGPTアプリで画像を貼り付けられない場合は「画像を保存」を利用する。
5. 画像を添付したあと、YubiSVGの **「AIに送る」** で修正したいパーツの情報をコピーし、同じチャットに貼り付けて修正内容を伝える。

**画像は自動で送信されません。** 自分で共有先を選ぶか、チャットにファイルを添付した場合だけ、その画像がChatGPTに渡ります。画像を共有する操作でSVGの図形や下絵の設定は変更されません。
共有用のPNGは、端末に保存された縮小済みの下絵から作成します。iPhoneの共有先一覧は端末ごとに異なるため、ChatGPTが共有候補に必ず出るとは限りません。

### ChatGPTで修正する

1. キャンバスで編集するパーツを選択する。
2. **「✦ AIに送る」→「文章をコピー」**。
3. コピーした文章をChatGPTに貼り付け、どう変えたいか伝える。
4. ChatGPTが返したJSONをコピーする。
5. YubiSVGの **「⇥ AI修正を貼る」** に入力し、確認して適用する。

ChatGPTとは自動接続ではありません。コピー＆ペースト方式です。

## プライバシー

この公開サイトに作品の自動アップロード機能はありません。編集データはこの端末のブラウザ内に保存されます。
Safariのデータ消去や端末変更で消えることがあるので、**「編集データ保存」**でJSONをこまめにバックアップしてください。

公開しているのはエディター本体（`index.html` と `client/` 内のスクリプト）のみです。
[MCP・PC同期機能の開発用リポジトリ](https://github.com/ShugureRune/svg-editor)にあるサーバーコードや作品ファイルはこのリポジトリに含めていません。

## 注意

- AI修正ができるのは、現在ベジェ曲線の制御点またはパーツの色・線幅です。
- 普通のSVGファイルを読み込んで再編集する機能はまだありません。編集用JSONを使ってください。
- スマホSafariでの実機操作感は今後確認して調整する段階です。
